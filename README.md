# ShellArena – Interactive Linux & DevOps Battle Platform

ShellArena is a real-time Linux and DevOps training platform built using Python Flask, Docker, WebSockets, and monitoring tools.

## Features
- Live Linux terminal
- Docker sandboxing
- Real-time command execution
- Prometheus monitoring
- Grafana dashboards
- XP & leaderboard concept

## Run Project

```bash
docker-compose up --build
```

Frontend: http://localhost:3000  
Backend: http://localhost:5000
